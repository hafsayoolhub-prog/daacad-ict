# DaacadICT Solutions Website

This repository contains the source code for the DaacadICT static website, built using React 18.

## 🚀 Project Overview

The website is a static client project developed to showcase the services offered by DaacadICT, including Web Development, Cybersecurity Solutions, and IT Consulting.

The development is a collaborative effort involving interns under supervision.

## 📁 Project Structure

The project follows a **page-based structure**, separating pages from reusable components to keep the codebase simple and maintainable.

## Pages
- Home
- About
- Services
- Seminars
- Contact

## Tech Stack
- React 18
- JavaScript
- Vite
- React Router
- Tailwind CSS

## Styling Rules
- Tailwind utility classes only
- No custom CSS unless approved
- No inline styles

## 🛠️ Installation & Setup

Ensure **Git** and **Node.js** are installed.

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd daacadict-website

2.  Install dependencies:
    ```bash
    npm install
    # or yarn install
    ```

3.  Run the application in development mode:
    ```bash
    npm run dev
    # or yarn run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    # or yarn build
    ```
    This creates a `build` (or `dist`) folder with optimized static files.
