# Intern Project Rules and Guidelines

Welcome to the DaacadICT development team. These rules ensure consistency and smooth collaboration. They are mandatory.

## 1. General Rules
- Use JavaScript only
- React functional components only
- One component per file
- Use clear, readable component names

## 2. Folder Rules
- Pages → `/pages`
- Reusable components → `/components`
- Layout components → `/components/layout`
- UI elements → `/components/ui`
- Images → `/assets/images`

Do NOT create new folders without permission.

## 3. Page Rules
- Pages handle layout and content only
- No duplicated UI between pages
- Shared UI must be moved to `/components`

## 4. Tailwind CSS Rules
- Tailwind utility classes only
- No inline styles
- No CSS files except `index.css`
- No Tailwind plugins without approval
- Keep long class lists readable

## 5. Code Quality
- Remove `console.log` before pushing
- Use semantic HTML
- Keep components small
- Write clear commit messages

## 6. Forbidden
- No APIs
- No state libraries
- No new dependencies
- No copying components between pages
- No editing config files without approval
